# Phase 7 — Generic OAuth Module Implementation Plan (optional path)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development — one Opus subagent per task. Every provider config is exercised by unit tests with mocked `fetch`; live checks only when the user supplies operator OAuth apps.

**Goal:** `lib/oauth` handles authorize → callback → seal → refresh for Slack, Notion, Airtable and Linear when operator OAuth apps are configured (`<PROVIDER>_CLIENT_ID/SECRET` in the environment); "Connect with OAuth" buttons render only then; token-paste connections (Phase 6) remain the default.

**Verified facts (docs/research/connectors-data.md, connectors-chat.md):** Slack redirect URLs must be HTTPS (no localhost exception) and `oauth.v2.access` takes HTTP Basic `client_id:client_secret`, response `access_token` (bot), `team.id`, `team.name`, `bot_user_id`, `scope` (granted; optional scopes may be declined), tokens do not expire unless rotation is enabled (never enable); Notion token endpoint uses Basic auth + `Notion-Version: 2026-03-11`, `owner=user`, response has `access_token`, `workspace_id`, `workspace_name`, `bot_id`, `refresh_token` (string|null), no `expires_in` → `expiresAt: null`, refresh on 401 with `grant_type=refresh_token` (returns a new pair); Airtable requires PKCE S256, token endpoint form-encoded with `code_verifier`, Basic auth when a client secret exists, access 60 min / refresh 60 days rotating; Linear OAuth tokens expire in 24 h (`expires_in: 86399`) with rotating refresh tokens (since 2026-04-01), `Authorization: Bearer` for OAuth tokens.

## File structure
```
lib/oauth/providers.ts   ProviderConfig per provider (authUrl, tokenUrl, scopes, scopeParam, extraAuthParams, clientAuth: "basic"|"body", pkce, refreshRotates, expires, pickFromResponse)
lib/oauth/pkce.ts        verifier/challenge (S256) + state
lib/oauth/index.ts       buildAuthorizeUrl, exchangeCode, refreshToken, isConfigured(provider)
lib/vault.ts (mod)       openFresh(): if expiresAt && expiresAt - 60s < now → refresh, re-seal (rotate pair), on invalid_grant → status needs_reconnect + FatalError
app/api/oauth/[provider]/start/route.ts     auth → state (+ verifier) stored in oauthStates (10 min) → 302
app/api/oauth/[provider]/callback/route.ts  state check → exchange → seal → connections row (label from pickFromResponse) → redirect /connections?connected=<provider>
convex/oauthStates.ts + convex/crons.ts     create/consume, hourly cleanup of expired states
components/connections/OAuthButton.tsx      rendered when /api/oauth/[provider]/configured says true
tests/oauth.test.ts
```
